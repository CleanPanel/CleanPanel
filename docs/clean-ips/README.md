# Clean exit samples

Real exit-location samples from a CleanPanel install. Each image shows
the result of an IP reputation check for one of the panel's exits:
country and city, the residential ISP (or "Other") badge, "Likely
Native", and Risk Score **0 (Low Risk)**.

**IP addresses and network ranges were intentionally removed before
publishing.** The screenshots are cropped and blanked so no IP address
or range appears anywhere — only the country, the ISP type, and the
score are shown. The original screenshots are not published.
