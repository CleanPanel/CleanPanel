# MooProxy

MooProxy منبع خروجی‌های IP رزیدنشال پنل است. خروجی‌هایی که از MooProxy
ساخته می‌شوند به‌جای آدرس دیتاسنتر، از IP رزیدنشال استفاده می‌کنند.

## چه چیزی لازم است

1. یک حساب MooProxy. سرویس MooProxy یک سرویس پروکسی رزیدنشال پولی است —
   در MooProxy ثبت‌نام کنید و یوزر و رمز پروکسی را از داشبورد آن بگیرید.
   پنل حساب آماده ندارد.
2. نسخه ۱٫۰٫۳۰ یا جدیدتر CleanPanel.

## راه‌اندازی

1. داشبورد را باز کنید → **تنظیمات → MooProxy**.
2. **فعال کردن MooProxy** را روشن کنید.
3. **یوزر پروکسی MooProxy** و **رمز پروکسی MooProxy** را وارد کنید (اگر
   رمز را خالی بگذارید، رمز فعلی حفظ می‌شود).
4. **هاست ورودی (Entry host)** و **پورت ورودی (Entry port)** — پیش‌فرض
   `us.mooproxy.net` و `55688` است. فقط اگر MooProxy نقطه ورودی دیگری به
   شما داد، آن‌ها را عوض کنید.
5. **مدت نشست (دقیقه — حداکثر 120)**: مدت زمانی که یک IP خروجی ثابت
   می‌ماند (نشست چسبان). پیش‌فرض ۱۲۰ دقیقه است.
6. **شکار موازی MooProxy**، **حداکثر تلاش هر شکار** (پیش‌فرض ۶۰) و **سقف
   ترافیک هر شکار (MB)** (پیش‌فرض ۵ مگابایت) نحوه اجرای شکار را کنترل
   می‌کنند.
7. تنظیمات را ذخیره کنید.
8. کشورهای شکار را انتخاب کنید: **تنظیمات → کشورهای MooProxy**.
   کشورهای پشتیبانی‌شده: آلمان (DE)، فرانسه (FR)، بریتانیا (GB)، هلند
   (NL)، ایالات متحده (US).
9. شکار را شروع کنید: **خروجی‌ها → شکار IP تمیز (MooProxy)**.

## نحوه کار

- هر نشست تا ۱۲۰ دقیقه یک IP خروجی ثابت دارد (نشست چسبان). در طول نشست
  IP عوض نمی‌شود.
- فقط IP با اسکور ۰ قبول می‌شود. خروجی کثیف حذف می‌شود.
- شکار از ترافیک حساب MooProxy شما استفاده می‌کند: هر تلاش شکار تا ۵
  مگابایت مصرف می‌کند و هر نشست سقف ترافیک ۴۰۰ مگابایت دارد.
- `moo-keeper` نشست را زنده نگه می‌دارد تا IP خروجی در طول نشست چسبان
  پایدار بماند.
- وقتی نشست تمام شود یا سقف ترافیک آن پر شود، خروجی با شکار یک مورد جدید
  جایگزین می‌شود.

## رفع مشکل

- **شکار ناموفق است یا چیزی پیدا نمی‌کند**: یوزر و رمز پروکسی، هاست و
  پورت ورودی را بررسی کنید و مطمئن شوید حساب MooProxy هنوز ترافیک دارد.
- **نشست زود تمام می‌شود**: سقف ترافیک ۴۰۰ مگابایت هر نشست پر شده است.
- **یک خروجی ناپدید می‌شود**: IP آن دیگر اسکور ۰ ندارد، پس پنل آن را
  حذف کرده است و جایگزین آن را شکار می‌کند.
