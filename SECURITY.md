# Security Policy

## Supported Versions

| Version | Supported |
| ------- | --------- |
| v1.0.30 | Yes |
| Older   | No        |

Only the latest release is supported. Please update to the latest version
before reporting a security issue.

## Reporting a Security Issue

If you find a security issue, please report it privately instead of opening
a public issue.

- Open a private security advisory on this repository, or contact the
  maintainer through the contact details listed on the repository profile.
- Describe the issue, the affected version, and the steps to reproduce it.
- Do not include credentials, tokens, server addresses or other sensitive
  values in your report.

## What Not to Include

Never put credentials, API tokens, server addresses or user data in a public
issue, pull request or comment.
